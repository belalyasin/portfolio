# Portfolio

Personal portfolio site of Belal Abu Hatab, built with React and bundled with Parcel.

Live site: https://belalyasin.github.io/portfolio/

## Development

```bash
npm install
npm start        # local dev server
npm run deploy   # build and publish to the gh-pages branch
```

Site content lives in `src/App.jsx` (name, title, contact links) and `src/Components/` (About and Portfolio sections).

Based on Microsoft's Codespaces portfolio template (MIT licence).
